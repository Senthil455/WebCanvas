# WebCanvas

A personal collection of small HTML, CSS and JavaScript experiments: animations, UI components, layout demos and interactive widgets.

Every folder is self-contained. Open its `index.html` in a browser to run the demo.

## Contents

- Layout and positioning: `Position Top Bottom Left Right Center`, `Float Property`, `Z-index`, `Display grid`, `Multiple Columns`
- Animation and motion: `CSS Animations`, `Box Animation`, `Battery Animation`, `Spinner`, `Type Writer`, `Typewriter Effect`, `Zoom Hover`
- Forms and inputs: `Forms`, `Input Date`, `Input Number`, `Check Checkbox`, `Color Picker`, `Color Picker Input`, `input-range`, `Select Tag`, `Toggle Password Visibility`, `Email Field`
- Navigation: `Navbar`, `Navbar With Icons`, `Mobile Menu`, `Side Bar`, `Sticky Social Bar`, `Fullscreen Navigation`, `Menus`, `Tabs`
- Feedback and state: `Progress Bar`, `Scroll-based progress bar`, `Traffic Signal`, `Tooltips`, `Pagination`
- Images and media: `Image Slider`, `Image Styles` and friends under `Image Hover Overlay`, `Image Overlay Title`, `Image Shapes`, `Image Styling`, `Multiple Backgrounds`, `Blurry Background Image`
- Scroll and overflow: `Scroll Bar`, `Infinite Scroll Bar`, `Scroll Top`, `Overflow`
